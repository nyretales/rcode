# R•CODE Resource Library — Notes

## Source files
- `html.md` — supplied collection of HTML/CSS/JavaScript UI assets.
- `prompt.md` — supplied collection of AI prompts.

## What is included
- 27 code/UI projects and 49 source-file blocks.
- 26 projects have a browser preview assembled from the supplied HTML/CSS/JS. The React + Vite example is labelled as requiring a build step.
- 60 prompt collections with 4,600+ extracted copyable prompt/use-case entries.
- The complete text of each prompt collection is preserved in the data file so the original wording can be referenced and copied.

## Pages
- `code-library.html`
- `prompt-library.html`

## Data
- `data/code-library.json`
- `data/prompt-library.json`

## Maintenance
Do not rename resource IDs casually; they are used by the catalogue interface. Update the relevant JSON record to change a title, description, source code, prompt, or category. The catalogue pages are static and do not require a backend.

## Preview limitations
Some examples rely on external libraries, local asset folders not present in the supplied markdown, or build tools. The preview is therefore a convenience for visual inspection, not a guarantee that every copied project runs without additional dependencies. The source code remains available for copying and adaptation.
